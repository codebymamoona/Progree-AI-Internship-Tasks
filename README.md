# Progree AI Internship Tasks

This repository contains the completed tasks for the AI Internship program at Progree.

## Repository Structure

- `Task1/`: LinkedIn announcement details and verification.
- `Task2_Sentiment_Classifier.ipynb`: Multi-class NLP sentiment classifier using pre-trained sentence embeddings and Scikit-Learn.
- `Task3_AStar_Pathfinding.ipynb`: Custom A* heuristic graph pathfinding agent with performance metrics.
- `Task4_Object_Detector.ipynb`: Real-time OpenCV segmentation and contour tracking pipeline.
- `Task4_Whitepaper.pdf`: 5-6 page detailed performance whitepaper for the CV pipeline.

## Tech Stack
- **Languages:** Python
- **Libraries:** NLTK, Scikit-Learn, Sentence-Transformers, PyTorch, OpenCV, NumPy, Matplotlib
